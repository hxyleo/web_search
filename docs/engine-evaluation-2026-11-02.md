# 搜索引擎评测：2026-11-02

## 范围和方法

在独立的临时 SearXNG 容器中，使用与正式服务相同版本的镜像逐个请求候选引擎。每次只指定一个引擎，临时实例设置默认请求超时 5 秒、上游搜索等待上限 8 秒。请求之间间隔较短，可能影响上游限流；搜索结果、网络状态与搜索引擎行为均可能变化。

首轮问题：

1. 中文技术：`Python FastAPI 教程`
2. 中文生活信息：`高铁行李尺寸限制`
3. 中文新闻：`人工智能 最新新闻`
4. 英文技术文档：`Python FastAPI dependency injection documentation`

记录响应时间、结果数、SearXNG 上游错误和前三条标题，并人工判断标题与问题的相关性。新闻搜索只检查主题相关性，未核实每条结果的发表时间；相关不等于内容正确或最新。

百度的验证码来自一次包含百度的请求；单独选择百度时已经处于暂停状态。没有绕过验证码，也没有将暂停状态当作独立网络请求。

## 正式服务联调

正式配置启用 Yahoo、Google CSE、360 搜索，设置 SearXNG 默认上游请求超时 5 秒、搜索等待上限 8 秒。上限控制 SearXNG 的搜索等待，并不保证完整 API 请求一定在 8 秒内结束。
